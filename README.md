# 🎓 Certificate Issuance System

This is a web application built with **React.js** that allows users to manage course information and generate customized certificates for candidates. The system provides an intuitive interface to enter, edit, delete, and display course data, upload certificate templates, and render downloadable certificates with drag-and-drop customization.

## 🚀 Features

- **Course Management Table**:
  - Add, edit, and delete multiple course details.
  - View all courses in a dynamic and responsive table layout.

- **Candidate Selection**:
  - Dropdown to select a candidate by name.
  - Automatically populate candidate-related course details.

- **Certificate Template Upload**:
  - Upload a background image to be used as the certificate template.
  - Render the certificate in real-time within the UI.

- **Drag-and-Drop Certificate Customization**:
  - Drag candidate/course details onto the certificate background.
  - Customize position and layout directly on the rendered view.

- **Certificate Download**:
  - Download the final customized certificate as an image or PDF.

## 🧰 Tech Stack

- **Frontend**: React.js
- **File Handling**: `html2canvas`, `jspdf`
- **Drag-and-Drop**: `react-dnd`, `react-draggable`
- **PDF Rendering**: `react-pdf`, `@react-pdf-viewer/*`
- **QR Code Support**: `qrcode.react`, `react-qr-code`
